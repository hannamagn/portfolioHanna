VibeTribe

A full-stack social platform designed for music lovers, built around communities, content creation and shared musical interests. Group project did in course Web Application at Chalmers University of Technology.

React JavaScript REST API React Hooks Bootstrap UX

About the group project

VibeTribe was created to be an online community platform created specifically for music enthusiasts. The idea was to create a space where people could connect through shared musical interests rather than through a traditional social media feed.

Users can explore communities called "tribes", each centered around a particular genre or musical interest. After creating an account, users can create their own tribes and publish posts containing recommendations, playlists, experiences and discussions about music.

The project focused both on building the functionality of a full-stack web application and on designing a simple, accessible user experience.

Frontend architecture

The frontend was built with React and structured around reusable components such as TribeList, Account, SignUp and CreateTribe.

React's component-based architecture allowed different parts of the application to remain separated while still being reusable throughout the interface.

We also applied several SOLID principles when structuring the application. Components were designed around individual responsibilities, while API communication was separated from the user interface through a service layer.

Authentication and validation

VibeTribe includes a complete account flow where users can register and log in before accessing functionality that modifies the platform.

Authentication state is also used for authorization. For example, users who are not logged in can browse tribes but cannot create a new tribe or publish content.

The forms include validation and clear error feedback. Invalid usernames, email addresses and passwords display messages directly next to the relevant input, helping users understand what needs to be corrected.

Backend and API communication

The frontend communicates asynchronously with the backend through API requests for functionality such as authentication, tribe management and post management.

API logic was abstracted into separate service functions rather than being handled directly inside the UI components. This keeps the frontend components focused on presentation and interaction while reducing dependencies between different parts of the application.

Posts can be created, fetched, updated and deleted through dedicated API routes, while React updates the interface with the resulting data.

What I learned

VibeTribe gave me practical experience developing a larger React application where frontend architecture, backend communication and user experience all needed to work together.

The project strengthened my understanding of component-based development, React hooks, authentication flows, API integration and separation of responsibilities within a web application.

It also highlighted how technical decisions such as state management, validation and API abstraction directly affect both maintainability and the experience of the end user.
